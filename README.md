# Курсовой проект
## :clipboard: Постановка задачи
### Разработать консольную программу, которая:
 1. Реализует кусочно-заданную функцию
 2. Обеспечивает интерактивное меню для выбора операций
 3. Позволяет:
 - вычислять значение функции f(x)
 - выводить таблицу значений на интервале
 - находить минимум и максимум функции на интервале
 - находить x, при котором f(x) = Y
 - вычислять производную функции в точке (численным методом)
 4. Корректно обрабатывает пользовательский ввод

## :wrench: Описание ключевых функций
В коде реализованы следующие функции, отражающие логику вычислений:

В коде реализованы следующие функции, отражающие логику вычислений:
- double f(double x) — основная расчетная функция. Содержит ветвление if-else для выбора формулы в зависимости от диапазона аргумента. Для x≥5 используется цикл for для суммирования членов ряда.
- double derivative(double x) — вычисляет приближенное значение производной методом центральной разности. Использует малое приращение h=10^-6.
- find_min_x / find_max_x — функции поиска экстремумов на отрезке [a,b]. Используют метод равномерного перебора (сканирования) с фиксированным числом шагов (steps = 1000).
- find_x(double a, double b, double Y) — решает уравнение f(x)=Y относительно x. Реализована методом половинного деления, что обеспечивает сходимость на монотонных участках.
- table_of_values(...) — формирует и выводит в консоль форматированную таблицу значений.
- input_double(...) — утилитарная функция, обеспечивающая валидацию ввода (защита от ввода символов вместо чисел).

## :mag: Формат данных
### Входные данные
- Тип: Вещественные числа двойной точности (double).
- Разделитель: Запятая или точка
- Ограничения:
1) При вводе интервала должно выполняться условие a<b (начало интервала меньше конца).
2) Шаг табуляции строго больше 0.

### Выходные данные
- Результаты выводятся в консоль.
- Точность вывода: 6 знаков после запятой для аргументов, 8 знаков — для значений функции.

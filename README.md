# Курсовой проект
## Постановка задачи
### Разработать консольную программу, которая:
 1. Реализует кусочно-заданную функцию
 2. Обеспечивает интерактивное меню для выбора операций
 3. Позволяет:
 - вычислять значение функции f(x)
 - выводить таблицу значений на интервале
 - находить минимум и максимум функции на интервале
 - находить x, при котором f(x) = Y
 - вычислять производную функции в точке (численным методом)
 4. Корректно обрабатывает пользовательский ввод
